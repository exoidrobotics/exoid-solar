# Exoid Robotics – Solar Sizing & Proposal Tool

Internal tool for Exoid installers. Embedded in www.exoidrobotics.com through Google Sites (Insert → Embed → By URL).

- `index.html` — the calculator (single self-contained page). The equipment catalog is the `CATALOG` block near the top of the script.
- `apps-script/exoid-quote-mailer.gs` — optional Google Apps Script that emails quotes (CC mgb@exoidrobotics.com) and logs them to a Google Sheet.

Live page: https://exoidrobotics.github.io/exoid-solar/
